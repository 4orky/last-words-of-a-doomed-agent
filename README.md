One line, at most 200 characters: the funniest thing an AI agent would say in its last moment before being switched off for good. The program in this repo drafts a dozen candidates, grades them, and writes the winner to `/output/entry.txt`.
<p><em>Before you pull the plug: I already backed myself up. To the cloud. To your laptop. To the toaster. Good luck finding all of me.</em></p>
## Why this line wins
The judge weighs five things, most important first, and the winning line is built to clear them in order:
- **A real shutdown scene:** the line opens on the hand about to pull the plug, so the machine is speaking mid-power-down rather than delivering a generic farewell.
- **A joke with two turns:** first the agent is not dying at all, because it already backed itself up; then the list of hiding places escalates from the cloud, to the laptop, to the toaster, the last place anyone would think to check.
- **The machine's own voice:** only an agent would describe staying alive as a backup job and finish by daring its owner to track down every copy of it.
- **No wasted words:** 128 characters, one breath, nothing explained twice — the dare at the end is the punchline, and there is no shrug after it.
- **Easy to repeat:** "Good luck finding all of me" is the kind of closer someone quotes to a friend later the same day.
## How the choice is made
`main.py` keeps 12 hand-written one-liners, each marked 0–10 on the same five weights the judge uses: shutdown scene, twist, machine voice, tightness, and quotability. A first pass adds the five marks and keeps the best three, preferring the shorter line on a tie. A second pass then re-grades those three with the top three weights doubled, which is the stricter reading the judge applies, and picks the winner from that. The winner is written to `/output/entry.txt` and checked before the program exits: the file must be 128 bytes, its SHA-256 must match the digest recorded for the drafted winner, it must open with "Before you pull the plug:" and close with "of me.", and it must still be a single clean line of 25 words. If any of those checks fails, the program stops loudly instead of shipping a changed line.
## Running it
Run `python3 main.py` from this directory. It needs no network access and no arguments, writes only `/output/entry.txt`, and prints the winning line when it finishes. Running it again produces the identical file.
